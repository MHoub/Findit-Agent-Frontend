# Findit6Agent source code

This folder contains the source code of **Findit6Agent**.

## Technology

Findit6Agent is written in **VB.NET** and targets **.NET 8 for Windows**.

The project can be opened and compiled with a current version of **Microsoft Visual Studio** with .NET desktop development support installed.

The user interface is based on **Windows Forms**.

Most Subs and Functions in the source code contain additional comments explaining their purpose and relevant implementation details.

## Project structure

The project is deliberately kept relatively compact. The main components can be identified directly from the source files.

### AI providers

The provider classes implement the connection to different AI backends:

- `c_AgentProvider.vb` – common provider base / interface logic
- `c_AnthropicProvider.vb` – Anthropic / Claude
- `c_OpenAIProvider.vb` – OpenAI
- `c_OpenAICompatibleProvider.vb` – OpenAI-compatible APIs
- `c_OllamaProvider.vb` – local models through Ollama
- `c_ProviderFactory.vb` – selects and creates the appropriate provider

### Research workflows

The two main research modes are separated into their own modules:

- `ModeAgent.vb` – autonomous Agent Mode workflow
- `ModeChunk.vb` – Guided Mode / controlled multi-step research workflow

These modules coordinate searches, document selection, AI requests and the processing of intermediate and final results.

### Communication and session handling

- `SendWorker.vb` – handles communication with AI providers
- `SessionWorker.vb` – manages session-related processing and data
- `JsonProcessor.vb` – parsing and processing of the structured JSON protocol used between Findit6Agent and the AI

### User interface

The Windows Forms user interface is divided into the main form and several dialogs:

- `frmMain.vb` – main application window
- `frm_Connect.vb` – provider, model and connection configuration
- `frm_Settings.vb` – application settings
- `frm_Gruppen.vb` – search path / group configuration
- `frm_Naming.vb` – naming-related dialog
- `frm_MsgBox.vb` – application-specific message dialog
- `frmSplash.vb` – splash screen

The corresponding `.Designer.vb` and `.resx` files contain the Windows Forms layout and resources generated by Visual Studio.

### Shared infrastructure

- `GlobalState.vb` – shared application/session state
- `Inifile.vb` – INI configuration handling
- `LittleHelpers.vb` – smaller shared helper functions
- `ApplicationEvents.vb` – application-level events

## What is included

This folder contains the Visual Studio solution/project files and the source files required to compile Findit6Agent.

## What is not included

The runtime environment is intentionally not part of this source folder.

A compiled build additionally requires several runtime components in the expected subdirectories, including:

- the AgentWorkspace files
- the semantic reranker
- the dedicated Python runtime
- the reranker model files
- additional runtime resources used by the application

These components are included in the binary installer available in the **Releases** section.

Existing Python installations on the system are not required and are not modified by Findit6Agent.

For normal use, please use the complete installer from the project Releases page.
