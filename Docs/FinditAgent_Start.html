Findit6Agent

An AI-assisted research tool for your existing file archive.

The goal is familiar from RAG: let AI work with your own data. The difference is that Findit6Agent works directly on the original archive - without prior indexing, vectorization or reorganization, and without giving the AI uncontrolled access to your files.

💡 Discover Findit6!

The search engine that allows an AI to find almost any file content for you in a very short time can also be extremely useful on its own — for humans, including you. Findit6 searches your existing files directly, without prior indexing, is exceptionally fast and is designed to be simple to use. Give it a try: Findit6 was installed together with Findit6Agent and can be recognized by its turquoise icon.

P.S.: If you have many scanned documents that you want to search using OCR, we recommend running the potentially time-consuming initial OCR scan directly from Findit6 anyway. Once OCR text has been cached, subsequent searches — including Findit6Agent searches — can be considerably faster.

Findit6Agent remains in control of the local archive. The AI receives search results and only machine-readable text from documents or excerpts selected for the current research task.

If your work involves searching large collections of documents, Findit6Agent can turn archive research that would otherwise require manual searching, specialized retrieval software or considerable staff time into an interactive, source-based research process.

Its particular strength is that it works directly with the archive you already have. New or recently changed files are immediately searchable, and the original data remains under your control.

Findit6Agent - First Steps

For your first search, only a few steps are required.

1. Define where Findit6Agent may search

Open Where to search and create or select a search path group. A path group defines the drives and folders Findit6Agent is allowed to search. Check the locations you want to include and confirm your selection with OK.

You can create several groups for different purposes - for example one for your main archive, another for current projects, or separate groups for private and professional data.

Findit6Agent and the AI work strictly within the locations included in the currently selected path group. A path group can contain folders from several drives; there is no need to reorganize your existing archive.

If you want Findit6Agent to search scanned documents using OCR, please also read the OCR note in the Technical Appendix at the end of this page.

💡 Chat subscription or API access?

A regular ChatGPT, Claude or similar monthly subscription normally covers chatting on the provider's website. Findit6Agent needs separate API access so the AI can work automatically in the background. API usage is billed by the amount of text processed; a typical search usually costs only a few cents. How to enable API access is explained on the website of the respective provider.

No API is required for local use: Guided Mode can run completely on your own computer with Ollama and a suitable local model. This requires Ollama and sufficiently capable hardware (typically 12 GB VRAM or more).

2. Connect an AI model

Choose Guided Mode or Agent Mode

Depending on the provider and type of model you use, Findit6Agent can work in different ways.

Large, high-capability models accessed through an API can plan and carry out a complex research process largely on their own. They can use Findit much like a human researcher would: decide what to search for, inspect the results, refine the search, read relevant sources and continue until they can produce a final answer. This is what Agent Mode is designed for.

Smaller language models - especially models that can run locally on your own computer - can also use Findit, but they benefit from a less complex workflow. In Guided Mode, Findit6Agent leads the model through a series of predefined research steps and supports the process with a local semantic reranker.

Agent Mode

For capable models that can plan searches, evaluate results, read selected sources and refine their own research strategy until they have enough evidence to answer.
You can chat with the Agent while it works, guide the research at any time, or simply let it work autonomously.

Agent Mode details

Guided Mode

For smaller and local models. Findit6Agent breaks the research into controlled stages and uses a local semantic reranker to help select relevant material.
There is no interactive chat during a Guided Mode search; the individual processing steps do not share a continuous conversational memory..

Guided Mode details

After choosing the working mode, select the provider and model you want to use.

When using an external provider, enter the required connection information and API key. With Ollama in Guided Mode, the AI processing itself can remain completely local.

Guided Mode is included with Findit6Agent.
The local Python environment and semantic reranker required by the Guided workflow are installed together with Findit6Agent. Ollama and a suitable local language model are only required if you want the AI processing itself to run locally.

Tell the Agent something about you

The Name of User and Basic information about User fields are especially useful in Agent Mode.

You can provide a short description of yourself, your work or the kind of archive you are searching. For example:

German TV journalist specializing in environmental and economic topics, with an archive growing since 1995.

This helps the Agent interpret otherwise ambiguous references. It may understand what you mean by “my reports”, recognize recurring project structures or understand why certain people, organizations or document types are likely to matter.

Keep this description short. It is useful background information, not a complete biography.

3. Ask your first question

Enter a question whose answer can reasonably be expected to exist somewhere in the selected archive. You do not need to write a Findit6 search expression yourself.

Guided Mode

Keep the question short, precise and focused on the information you want to find. Avoid telling the AI how to perform the search; the Guided workflow determines the individual processing steps automatically.

Multi-word technical terms and known synonyms can still be supplied explicitly when useful, for example "combustion engine" or car ((automobile, vehicle)).

Agent Mode

You can formulate the request more freely and provide additional information that may help the Agent understand your archive or develop a better search strategy. Useful hints about folder structures, naming conventions, document types, people, projects or other archive-specific knowledge can significantly improve the research.

🔒 The AI never has access to your files

The connected AI never has access to your file system or your files - in any form. It cannot open, read, create, write, modify, copy, move or delete files on your computer.

Think of the AI as a visitor standing in front of the secure archive. It cannot see what is stored in the stacks and cannot open a single drawer itself. The archivist - Findit6Agent - performs all searches and file access, selects material relevant to the current task and hands the AI only a working copy of the required text or text excerpts.

Your original files remain untouched on your drives at all times.

When you use an external AI provider, only text explicitly supplied by Findit6Agent is transmitted to that provider for processing. With a fully local setup, even this copies of text remain on your computer as well.

4. Start the search

Press Start / Send.

Findit6Agent now performs the required processing steps and shows them in the visible protocol.

A search may take several minutes, especially when AI reasoning or many documents have to be evaluated. The Findit6 full-text search itself is usually very fast even across large archives; much of the remaining time is spent constructing searches, evaluating results and reading relevant material.

You can watch the individual steps while they happen - or simply return a few minutes later and read the result. Whenever possible, the final answer includes references to the source files from which the information was derived.

Example workflow

In a typical Agent Mode research run, the Agent may search more than 50,000 files, reduce hundreds of initial matches to a manageable set of candidates, inspect selected source documents and produce a referenced answer within a few minutes.

The exact duration depends on archive size, hardware, model, provider and the amount of evidence the question requires.

That's it

You are now ready to use Findit6Agent. There is no need to import your archive, build a database or wait for an indexing process. Select where to search, connect an AI model and ask a question.

As you become more familiar with the system, the detailed documentation explains how Guided Mode and Agent Mode work, how local and external AI models differ and how the individual workflows can be customized.

Hardware requirements

Agent Mode with external AI

Agent Mode with an external AI provider can be used on practically any reasonably current Windows computer. No dedicated GPU is required. Findit6 itself benefits from more CPU cores, higher clock speeds and fast storage, so older laptops will generally search more slowly than modern desktop systems. In normal use, however, archives up to around 100 GB can still remain practical on older hardware.

Guided Mode with external AI

Guided Mode also works well with external AI providers, but adds a local semantic reranker. Whenever possible, the reranker uses the graphics processor through DirectML. On systems with limited graphics hardware - especially integrated graphics and smaller or older laptops - DirectML may not be usable reliably. Findit6Agent then automatically falls back to CPU-based reranking.

CPU reranking produces the same full-length reranking workflow, but can be considerably slower. Depending on the hardware, the number and length of candidate documents and the complexity of the search, reranking time can increase substantially and may become impractical for some workloads.

Fully local operation with Ollama

Running the AI itself locally through Ollama requires significantly more capable hardware. Findit6Agent is designed for local models starting at roughly the 14B class. For models around this lower end, at least 12 GB of VRAM should be available, with 16 GB or more recommended. Larger models may require correspondingly more VRAM. A GPU in this class will normally also provide sufficient performance for the local semantic reranker.

Performance varies with the workload.
Search speed depends on archive size, CPU performance and storage speed. Guided Mode additionally depends on reranker performance, while fully local AI also depends heavily on GPU speed and available VRAM.

Technical Appendix

System requirements

  • Windows 10 or Windows 11, 64-bit.
  • Sufficient free disk space for Findit6Agent, local AI models and temporary Session Workspace data.
  • An Internet connection is required when external AI providers are used and when models or components are downloaded. A fully local Guided Mode workflow can operate without sending archive content to an external AI provider.

OCR and scanned documents

Findit6Agent can also read and search scanned documents using OCR. Enable OCR when required using the checkbox at the top of the application.

OCR processing can take considerably more time than normal text extraction. Once text has been extracted from a document, Findit6 stores the result in a small local cache so that the same document normally does not have to be processed again.

Before using OCR extensively with Findit6Agent, it is therefore recommended to start Findit6 itself once and run an arbitrary search across the relevant data collection with OCR enabled. This allows the OCR cache to be built in advance and can make subsequent Agent searches significantly faster.

Guided Mode and local AI

  • Findit6Agent includes the local Python runtime and semantic reranker required by Guided Mode.
  • A DirectML-compatible GPU is recommended for semantic reranking.
  • Local AI through Ollama requires Ollama and a suitable local language model.
  • For local operation, models starting at roughly the 14B class are recommended. Around 12 GB of VRAM is a practical minimum for models near this lower end; 16 GB or more is recommended, and larger models may require correspondingly more VRAM.
No archive preparation is required.
Findit6Agent does not require prior indexing, vectorization or import of your archive. It works directly with the configured files and folders.

Troubleshooting and Support

Findit6Agent is the first release of a new kind of research tool. We have tested it with great care and expect it to work directly after installation on the vast majority of systems. However, the number of possible combinations of Windows systems, hardware configurations, AI providers and models makes it impossible to test every environment in advance.

If you encounter a problem, please contact us at findit@dateisuche.de. We will try to identify and resolve the issue as quickly as possible.

Findit6Agent creates a log file for every research run. As soon as you connect to an AI provider, a folder icon appears in the lower-right corner of the application. It opens the session folder containing the corresponding *.log file.

If possible, please attach this log file to your support request. It contains information about the individual processing steps, provider responses and errors and can make it considerably easier to identify the cause of a problem.

Before sending a log file, please review it if your research involves confidential file names, paths or document content. Depending on the search, such information may be included in the log.
